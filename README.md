# OSU Revelation Outdoors Website

A simple mobile-friendly landing page for Revelation Outdoors at Oklahoma State University.

## Files

- `index.html` — page content and links
- `styles.css` — OSU orange styling and responsive layout
- `script.js` — reserved for future interactive features

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `osu-revo-website`).
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the root of the repository.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. GitHub will provide a public URL such as `https://YOUR-USERNAME.github.io/osu-revo-website/`.

## Custom domain

Do **not** upload a `CNAME` file until you own the domain you want to use and have configured its DNS records for GitHub Pages. The original upload contained `ourevelationoutdoors.com`; that domain should not be attached to this OSU site unless you control it and intend to point it here.

## Editing links

Open `index.html` and change the `href="..."` value for any Instagram, GroupMe, Google Form, event, or main-site link.
