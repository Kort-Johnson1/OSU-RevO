# Revelation Outdoors OSU link hub

This is a simple GitHub Pages landing page for Revelation Outdoors at Oklahoma State University.

## Current links
- Main Revelation Outdoors website
- OSU RevO interest form
- OSU RevO GroupMe

## Publish on GitHub Pages
1. Upload all files in this folder to your GitHub repository.
2. Make sure the `assets` folder is present with both camo image files inside.
3. In the repository, go to **Settings → Pages**.
4. Set the source to the `main` branch and `/ (root)`.
5. Save and wait for the GitHub Pages URL to appear.

## Repository structure
- `index.html`
- `styles.css`
- `script.js`
- `README.md`
- `CNAME` (only use if you are connecting a custom domain)
- `assets/`
  - `ou-camo-new.png`
  - `ou-camo.png`
